
# Student Gradebook - Automated Testing Project

## 1. Project Description

The Student Gradebook is a Python application developed to demonstrate automated software testing.

It manages student records and marks using a simple Python module.

## 2. Features

- Add student records
- Retrieve student details
- Update student marks
- Remove student records
- Calculate average marks
- Assign letter grades
- Validate user inputs
- Handle missing student records

## 3. Technologies Used

- Python
- unittest framework
- Visual Studio Code
- Git and GitHub

## 4. Testing Methodology

This project demonstrates Test-Driven Development (TDD).

The testing process includes:
1. Identifying application requirements.
2. Preparing test cases.
3. Implementing application functionality.
4. Executing automated tests.
5. Identifying and correcting errors.
6. Reviewing and improving the code.

## 5. Test Cases

A total of 17 automated test cases were implemented.

They cover:
- Student addition and retrieval
- Case-insensitive searching
- Duplicate student validation
- Empty name validation
- Invalid marks
- Negative marks
- Marks above 100
- Minimum and maximum marks
- Updating student marks
- Removing student records
- Missing student exceptions
- Average calculation
- Grade calculation
- Complete student lifecycle

## 6. How to Run

Step 1: Install Python 3.9 or newer.

Step 2: Open the project directory.

Step 3: Execute:

python -m unittest discover -s tests -v
